  included-patches  = add a NON-default patch        build.sh:252 requires quotes
  excluded-patches  = drop a default patch

  inclusive-patches = true  -> start from everything, prune with excluded-patches

DEFAULT-OFF (2)  <- eligible for included-patches
--------------------------------------------------------------------------

'Clone app'
    Changes the app package name to allow installing the same app multiple times. By default
    ".morphe" is appended to the package name. Each cloned install must use a unique package name.
    Cloning does not work with all apps and using this patch may cause app crashes or other
    unexpected behavior.
    versions: any (unpinned)

'Enable DCIM folders backup control'
    Disables always on backup for the Camera and other DCIM folders, allowing you to control backup
    for each folder individually. This will make the app default to having no folders backed up.
    versions: 7.92.0.977185651, 7.80.0.929302933

--------------------------------------------------------------------------
DEFAULT-ON (3)  <- applied automatically; drop with excluded-patches
--------------------------------------------------------------------------

'Spoof features'
    Spoofs the device to enable Google Pixel exclusive features, including unlimited storage.
    versions: 7.92.0.977185651, 7.80.0.929302933

'GmsCore support'
    Allows the app to work without root by using a different package name when patched using a
    GmsCore instead of Google Play Services.
    versions: 7.92.0.977185651, 7.80.0.929302933

'Fix selected account persistence'
    Prevents Google Photos from clearing the selected account after cold start when using MicroG.
    versions: 7.92.0.977185651
