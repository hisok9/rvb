'Clone app'
    Changes the app package name to allow installing the same app multiple times. By default
    ".morphe" is appended to the package name. Each cloned install must use a unique package name.
    Cloning does not work with all apps and using this patch may cause app crashes or other
    unexpected behavior.
    versions: any (unpinned)

'Change installer source'
    Spoofs the installer source so the app appears to be installed from an app store.
    versions: any (unpinned)

'Override certificate pinning'
    Overrides certificate pinning, allowing to inspect traffic via a proxy.
    versions: any (unpinned)

'Spoof signature'
    Spoofs the package signature of the original APK.
    versions: any (unpinned)

'Disable Play Store updates'
    Disables Play Store updates by setting the version code to the maximum allowed. This patch may
    cause unexpected issues with some apps and does not work if the app is installed by root
    mounting
    versions: any (unpinned)

'Network proxy'
    Adds settings to route supported network requests through an HTTP or HTTPS proxy. Including this
    patch may cause connectivity problems on certain devices
    versions: 21.39.522, 21.38.130, 21.28.208, 21.23.492, 21.16.256, 21.13.164, 20.31.42, 20.21.37
